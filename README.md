# Hey, welcome!

My name's Pablo and I'm a Computer Engineering student at **UFERSA**, focused on embedded systems development, backend development, and infrastructure. My work spans from low-level programming on microcontrollers to building robust web systems, combining hardware, security, and automation.

### Actual Focus and Projects
* **Embedded Systems & IoT:** Hands-on development across various microcontrollers. Practical implementations include an **Inverted Pendulum** control system, a **handle-controlled cart** utilizing NRF transceivers for wireless communication (transmitter and receiver units), and a co-authored [research paper on the feasibility and benchmarking of PQC](https://periodicos.ufv.br/jcec/article/view/21741) on low-resource devices evaluating quantum-resistant algorithms using `wolfSSL`.
* **Backend Development:** Architecting applications and microservices in **Python**, building scalable systems with **Django** and **PostgreSQL**. A key example is the development of the patent management system for the Technological Innovation Center (NIT) at UFERSA.
* **Infrastructure & Automation:** Linux enthusiastic (Arch Linux user) and cross-platform automation. I write administration routines and scripts for Windows environments using **PowerShell** and **Batch**. 
* **Hardware Modding & Networking:** Repurposing older mobile hardware to operate as dedicated local Linux terminals (e.g., via LineageOS), along with network configuration, subnet isolation, and managing local LLM inference servers (`llama.cpp`).
